LLM Observatory

LLM features degrade quietly. This is the instrument that notices.

A prompt change or a model update can raise hallucination rates and cost long before any health check reacts. Teams running support, sales, and research endpoints usually can't say which one is expensive, or which one is getting worse.

  • Scored per trace. Faithfulness, relevancy, and hallucination, with LLM-as-judge and a deterministic fallback.
  • Incidents, not alerts. A threshold breach opens an incident that moves acknowledge to resolve.
  • Cost attributed. Tokens and dollars per endpoint, per model, per window.

Enterprise RAG

Most RAG systems filter the answer. This one never retrieves the document.

Applying access control after retrieval means a contractor can still pull a restricted file if the question is phrased well enough. Here the restricted documents leave the candidate set before any AI processing happens — the screenshot below is the same question asked twice, once as an employee and once as finance.

  • Enforced before retrieval. Not filtered out of the response afterwards.
  • No citation, no answer. Every response names its source document, chunk, and retrieval score.
  • Leakage is measured. A built-in eval set tracks citation coverage and restricted-document leakage as numbers.

FastAPI · Azure AI Search · Entra ID · Key Vault · PostgreSQL

Document Intelligence Workbench

A confidence score for every field, not a pass or fail for the page.

Finance and legal teams key invoice and contract data into downstream systems by hand. It's repetitive, it's error-prone, and it leaves no record of what was extracted, what was corrected, or who changed it. The reconciliation problem shows up weeks later.

  • Rules, not vibes. Invoice totals must match line items; contract expiry must follow the effective date.
  • Low confidence routes to a person. Nothing reaches a downstream system unreviewed.
  • Corrections are evidence. Every extraction and approval is logged with a timestamp, an actor, and a payload.

FastAPI · Azure Document Intelligence · Blob Storage · PostgreSQL

ProcureAI

When a regulator asks why a $200,000 purchase was approved, the answer shouldn't be in an email thread.

Purchase approvals run on institutional memory rather than the policy document. Budget checks happen by email. Vendor risk gets assumed. Five specialist agents — policy, vendor, budget, risk, and approval — each validate one domain and hand back a typed result.

  • Decisions cite the clause. The policy agent retrieves the exact text from indexed policy, not a generic rule.
  • Agents don't parse strings. They exchange typed message schemas over A2A, with no hidden state.
  • Every request produces a packet. Structured, exportable, and built to be handed to an auditor.

FastAPI · LangChain · MCP · A2A · PostgreSQL · Azure OpenAI

Multi-Agent Orchestration

A workflow that pauses for a human, survives a deploy, and remembers exactly where it stopped.

Enterprise workflows that cross systems run on email chains and spreadsheet trackers. No persistent state, no guaranteed record, no visibility into where something is or who touched it. Human review here is a genuine interrupt in the LangGraph state machine with a typed resume payload — not a polling loop.

  • State outlives the process. Workflows resume across restarts, deployments, and failures.
  • Append-only trail. Every agent action and human decision, timestamped and actor-tagged.
  • Verified without a live model. A 13-case golden eval at 100%, and 94 passing tests.
